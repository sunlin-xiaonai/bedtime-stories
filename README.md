# 晚安故事（开发版）

TikPal Voice 的离线睡前故事播放器。当前设备安装了 29 篇普通话故事，约 105 分钟；完整音频存放在 SD 卡的 `/sdcard/bedtime/`，占约 13 MB。应用本身内置其中 3 篇，SD 卡不可用时仍可以播放这 3 篇。故事来自 Storybooks Canada，按 CC BY 3.0 或 4.0 许可整理；每篇的作者、译者、朗读者、原始链接及许可见 [AUDIO-CREDITS.md](AUDIO-CREDITS.md)。转码音频和完整清单保存在 [research/storybooks-sd](research/storybooks-sd/)。

这些作品是独立的短篇故事，并非《猫和老鼠》《托马斯和朋友们》或《爆笑虫子》系列音频。其他许可为非商业用途的作品也没有放入此版本；如要公开发布，还需要按各自许可提供完整署名，并另行核实相关角色及录音的授权。

## 操作

- 主画面左右滑动切换故事，轻点封面播放或暂停；上滑进入书架。书架可以上下滑动浏览，轻点故事立即播放，短按侧键返回。
- 书架底部可切换“精选循环”和“单篇循环”。精选循环会依次播放初步筛选的 13 篇故事；另外 16 篇标记“陪同”，需要家长自行选择。筛选不能替代适龄审核，建议家长先听过，再决定是否给 3–6 岁儿童播放。
- 轻点定时按钮可依次切换 15、30、60 分钟和不限时，默认 15 分钟；播放模式和定时选择会保存。定时从播放开始计时，暂停期间也会继续计时。
- 主画面播放时短按侧键暂停；熄屏后短按唤醒；双击侧键由系统处理。熄屏时间遵循设备共享设置。暂停后继续的位置依据时间估算，可能重复一小段音频。

## 开发与安装

`./kit build` 构建并运行主机测试，需要 ESP-IDF 5.5.5。开发机验证使用 TikPal Voice 主固件 0.1.13；应用清单的最低主固件版本为 0.1.10。使用开发包的应用安装命令安装到指定扩展槽位；本次设备使用 `./kit install --slot 2`，不要执行全片擦除或主固件刷写命令。

若需要重新导入素材，先启动应用并连接 USB，然后使用已安装 `pyserial` 的 Python 运行：

```sh
python3 tools/import_sd.py --port /dev/cu.usbmodem1101 --package research/storybooks-sd
```

按实际设备修改串口名。导入程序仅向应用的 `bedtime` 目录写入四位编号的故事文件，检查长度和 SHA-256；已存在且不同的文件会保留，不会格式化 SD 卡。导入后重新启动应用以刷新书架。

已在设备上验证 SD 卡识别、故事导入校验、一篇 SD 故事播放后的精选续播和单篇循环，以及缩短时间的定时停止；触屏操作和全部故事的音质仍需继续实测。
