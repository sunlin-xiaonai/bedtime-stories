# 晚安故事

Tikpal Voice 的离线睡前故事播放器。用家长账号，陪孩子一起听（4+）。应用内置三篇 Storybooks Canada 普通话故事；另外 26 篇可选故事可以自行拷入 TF 卡。录音按 CC BY 许可使用，作者、译者和朗读者见 [AUDIO-CREDITS.md](AUDIO-CREDITS.md)。

## 操作

- 轻点封面播放或暂停，左右滑动切换，上滑打开书架。轻点书架里的条目立即播放，短按侧键返回。
- 「精选循环」只自动播放已筛选且可用的中文故事；其余故事需家长点选。请家长先试听，再选择适龄内容。「单篇循环」重复当前选中的条目。
- 定时按钮可选 15、30、60 分钟或不限时，默认 15 分钟。定时和播放模式保存在设备上；暂停时仍继续计时。暂停后恢复位置为估算值，可能重复一小段。
- 播放时短按侧键暂停，熄屏后短按唤醒，双击由系统处理。应用不收集用户数据。

## TF 卡上的音频

TF 卡是可选的。把 `research/storybooks-sd/bedtime/` 中想听的故事文件拷进卡根目录下的 `bedtimestories/`，保留原文件名和署名。也可以在同一目录放入家长有权使用并已试听的个人音频。应用只在本机读取这个目录，个人音频不随应用分发。

个人音频采用分包 Opus 格式，文件名为四位数字加 `.bin`（例如 `8000.bin`），单个文件不超过 2 MiB。不要使用故事包已有的编号。普通 MP3 等文件可在电脑上用 FFmpeg 转换：

```sh
python3 tools/pack_local_audio.py input.mp3 8000.bin
```

把生成的文件拷到卡的 `bedtimestories/` 目录，重新打开应用。书架按编号最多显示 16 段，统一标为「本地音频 + 编号」。精选循环不会自动播放这些文件；手动点选后播完即停，选「单篇循环」可重复当前音频。0.2.4 起目录从 `bedtime/` 改成 `bedtimestories/`（应用只用自己的目录 `/sdcard/<简称>/`）：以前拷在 `bedtime/` 里的文件，请在电脑上把整个文件夹改名成 `bedtimestories`，文件本身不用改。

## 构建

使用 Tikpal 开发包 v1.9 和 ESP-IDF 5.5.5。最低主固件为 0.1.14。

```sh
./kit test
./kit build --release
./kit check
```
