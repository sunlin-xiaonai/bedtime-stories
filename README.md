# 晚安故事（开发中）

TikPal Voice 离线睡前故事播放器，包含三篇普通话录音：和植物聊天的卡莱、我喜欢看书、数数动物。来源、作者、译者、朗读者和许可见 [AUDIO-CREDITS.md](AUDIO-CREDITS.md)。内容尚未完成适龄和真机音质审核。

左右滑切换故事，轻点主画面播放或暂停；上滑查看书架，点故事播放，下滑返回。播放时短按侧键暂停；熄屏后短按唤醒；双击侧键由系统处理。播放开始后 15 分钟停止；当前暂不提供修改定时的界面。息屏时间遵循设备共享设置（设置为不息屏时不会自动熄屏）。暂停后继续的位置依据时间估算，可能重复一小段。

`./kit build` 构建并运行主机测试。环境需要 ESP-IDF 5.5.5。固件只在开发包所规定的扩展位置测试；绝不擦整片 Flash 或写入主固件。当前尚未进行设备安装与真机验证；设备主固件需满足清单中的最低版本 0.1.10。资源署名在正式提供前还需以用户能访问的形式呈现。
